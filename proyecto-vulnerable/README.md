# TiendaVuln

Tienda en línea de ejemplo compuesta por tres módulos:

- `backend/`: API de la tienda (Spring Boot, Java 17). Maneja usuarios, inicio de sesión, pedidos y pagos.
- `reportes/`: servicio interno de reportes de ventas (Django).
- `frontend/`: interfaz web de la tienda (React).

Para levantar el entorno local:

```bash
docker-compose up --build
```
